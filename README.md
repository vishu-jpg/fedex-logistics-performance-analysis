# FedEx Logistics Performance Analysis

## Project Overview
This project analyzes FedEx logistics data to understand shipment
patterns, delivery delays, freight costs, and vendor performance.

## Objectives
- Analyze shipment modes and shipment volumes.
- Calculate delivery delays and delay rates.
- Compare freight costs across countries.
- Study the relationship between shipment weight and freight cost.
- Analyze missing values, outliers, and monthly shipment trends.

## Dataset
SCMS Delivery History Dataset

Source:
https://raw.githubusercontent.com/Franklin251198/Fedex-logistics-performance-analysis/main/SCMS_Delivery_History_Dataset.csv

## Tools and Libraries
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- SciPy

## Key Findings
- Air was the most frequently used shipment mode.
- Overall delivery delay rate was approximately 11.49%.
- Ocean had a higher observed delay rate than Air.
- Shipment weight and freight cost showed a strong positive association.

## Important Note
Correlation does not prove causation. Statistical outliers were
analyzed carefully rather than automatically removed.
